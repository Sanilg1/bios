Responsible AI Access Gate

A contributor-owned solution by Team Netra, built on the NamoID identity platform from an open community challenge.

Read the challenge View source →

THE IMPLEMENTATION

No permanent keys.

Requests for mock models, datasets and H100 time state a purpose, a duration and risk controls. A manager, a risk reviewer and the resource owner approve, narrow or reject. Access expires on its own, works only for what was approved, and can be revoked instantly, with a receipt for every decision. Everyone signs in through NamoID Hosted Auth. All resources and outputs are mock; approval does not make use safe.

This static page is the template's landing page. The working app is a Node server: see the README to run it.
